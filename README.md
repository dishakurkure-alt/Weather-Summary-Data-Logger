The Weather Summary & Data Logger is a Python-based project developed using Jupyter Notebook that focuses on collecting, processing, and storing weather data from online sources. The project demonstrates how raw, unstructured web data can be transformed into a clean and structured format using core Python programming concepts.

Weather information is extracted through web scraping with requests and BeautifulSoup. Regular Expressions (RegEx) are used to accurately parse relevant weather details from HTML content. The processed data is organized using Python data structures and stored using file handling, enabling persistent data logging.

The project is structured using functions and Object-Oriented Programming (OOP) principles to ensure modular, readable, and maintainable code. Exception handling is implemented to gracefully manage network errors,parsing issues, and unexpected data formats.

This project highlights the importance of data preprocessing, a critical step in data analysis workflows, ensuring accuracy and reliability for downstream analysis and reporting. It effectively showcases skills in web scraping, data cleaning, automation, and structured data handling, making it suitable for Data Analyst, Python Developer, and analytics-focused roles.
